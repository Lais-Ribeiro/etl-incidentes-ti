# Pipeline de Dados para Gestão de Incidentes de TI

Projeto de laboratório para estudo de **Engenharia de Dados**.

---

## 🎯 Objetivo

Construir um pipeline de dados capaz de coletar, processar e disponibilizar informações sobre incidentes de TI, garantindo qualidade, padronização e confiabilidade dos dados para apoiar análises operacionais e tomada de decisão.

---

## 🏗️ Arquitetura do Projeto

Fluxo principal:

**Dados brutos**
**Validação**
**Transformação**
**SQLite**
**Power BI**

---

## 🚀 Tecnologias

- Python
- SQL
- SQLite
- Pandas
- Power BI
- Git
- GitHub

---

## 🗺️ Roadmap

- [ ] Gerar dados fictícios de incidentes.
- [ ] Validar e tratar a qualidade dos dados.
- [ ] Padronizar informações utilizando tabelas de referência.
- [ ] Carregar os dados em um banco SQLite.
- [ ] Criar Ondicadores e visualizações no Power BI.
